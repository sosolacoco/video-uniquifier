# Video Uniquifier

Массовая уникализация видео через **FFmpeg**. Из каждого исходника делает N копий,
каждая — с уникальным случайным набором микро-изменений (скорость, обрезка, цвет,
кадр 9:16, PNG-оверлей, аудио). Есть **окно с кнопками** (GUI) и командная строка.

---

## 🟢 Быстрый старт (самый простой путь)

1. **Установи Python** с https://www.python.org/downloads/ — при установке поставь
   галочку **«Add Python to PATH»**.
2. **Установи FFmpeg** (нужен всегда, и для GUI, и для .exe). В PowerShell:
   ```powershell
   winget install --id Gyan.FFmpeg
   ```
   Затем **закрой и открой заново** терминал. Проверка: `ffmpeg -version`.
   > Не хочешь ставить в систему? Скачай `ffmpeg-release-full` с
   > https://www.gyan.dev/ffmpeg/builds/ , распакуй и укажи путь к `ffmpeg.exe` /
   > `ffprobe.exe` прямо в полях программы.
3. **Положи файлы по папкам** (см. ниже «Куда что класть»).
4. **Запусти программу** — двойной клик по **`Запустить_GUI.bat`**.
   Или из терминала: `python video_uniquifier_gui.py`.
5. Нажми **Старт**. Готовые ролики появятся в `output_videos/`.

Первый запуск: `pip install -r requirements.txt` (ставит `tqdm`).

## 📁 Куда что класть

```
skript/
├─ input_videos/     ← СЮДА кладёшь исходные видео (mp4, mov, mkv, avi, webm...)   [обязательно]
├─ output_videos/    ← отсюда забираешь результат (создаётся автоматически)
├─ audio_tracks/     ← фоновые треки (mp3/wav/...) — нужны ТОЛЬКО для режима «background»
├─ overlays/         ← PNG-картинки-оверлеи (фейк-точки/уведомления) — по желанию
│
├─ video_uniquifier_gui.py   ← окно с кнопками (запускай это)
├─ video_uniquifier.py       ← сам движок (можно и из командной строки)
├─ Запустить_GUI.bat         ← двойной клик = открыть окно
├─ Собрать_EXE.bat           ← двойной клик = собрать VideoUniquifier.exe
└─ requirements.txt
```

- **Минимум для работы:** кинуть видео в `input_videos/` и нажать Старт.
- **overlays/** и **audio_tracks/** можно оставить пустыми — программа просто не будет
  их использовать.

## 🖥️ Окно программы (GUI, тёмная тема)

Все параметры обработки настраиваются прямо в окне (галочки, поля, спинбоксы):

**1 · Папки** — исходники / результат / аудио / оверлеи (кнопка «Обзор…»).

**2 · Основное**
- Копий из каждого видео.
- Аудио: `mute` (без звука) / `background` (трек из `audio_tracks/`) / `keep` (оригинал).
- Накладывать фейк-точки (случайный PNG из `overlays/`).
- Резать длинные видео на отрезки 6–8 c (✅ вкл / ⬜ выкл — переключатель нарезки).

**3 · Длина, обрезка, скорость** (мин/макс диапазоны)
- Финальная длина (по умолч. 6–8 c).
- Обрезка с края (по умолч. 0.01–0.10 c).
- Скорость ± отклонение (по умолч. 0.01–0.10 → ±1…10%). Гарантированно ускоряет/замедляет.

**4 · Формат и качество** — кадр Ш×В (9:16 = 1080×1920), FPS, CRF, число процессов, seed,
перезапись, уникальные метаданные, проверка уникальности в конце.

**5 · Цветокоррекция и эффекты** (всё включается/выключается)
- Цветокоррекция — сила каждого канала в % (Яркость / Контраст / Насыщенность / Гамма).
- Шум · Резкость · Микро-зум — каждый с настройкой максимальной силы.

**6 · FFmpeg** — пути к `ffmpeg`/`ffprobe`, если они не в PATH.

Внизу: **Старт**, **Отмена** (мягкая остановка), **Проверить FFmpeg**, прогресс-бар и лог.

## ⚪ Фейк-точки (тап-индикаторы)

В комплекте уже лежат **20 готовых полупрозрачных точек** в `overlays/` (кольца,
свечения, «пульсации» разных размеров). На каждую копию накладывается **случайное
число** точек в **случайных местах** — настраивается в блоке «2b · Фейк-точки»:
- **Точек на видео** — диапазон (напр. 1–4).
- **Прозрачность** — 0.6 по умолчанию; меньше = незаметнее.
- **Размер** — доля кадра.

Перегенерировать набор: кнопка **«Сгенерировать 20 точек»** в окне, или из терминала:
```bash
python generate_dots.py --count 20
```
Можно класть и свои PNG (прозрачный фон) в `overlays/` — они тоже будут использоваться.

## 📦 Сделать .exe (чтобы запускалось двойным кликом без Python)

Двойной клик по **`Собрать_EXE.bat`** — соберёт `dist\VideoUniquifier.exe`.

Вручную то же самое:
```powershell
pip install pyinstaller tqdm
pyinstaller --onefile --noconsole --name VideoUniquifier --add-data "video_uniquifier.py;." video_uniquifier_gui.py
```

> ⚠️ Даже собранному `.exe` **нужен FFmpeg** в системе (или пути к `ffmpeg.exe`/`ffprobe.exe`
> в полях программы). FFmpeg — отдельная внешняя программа, внутрь .exe не встраивается.

## ⌨️ Командная строка (по желанию)

```bash
# 5 копий, без звука, случайные окна
python video_uniquifier.py --copies 5 --audio mute --workers 4

# последовательная нарезка длинных видео + фоновая музыка
python video_uniquifier.py --copies 3 --segment sequential --audio background

# сохранить исходный звук, без оверлеев
python video_uniquifier.py --audio keep --no-overlay

# воспроизводимый результат
python video_uniquifier.py --seed 12345
```

Все флаги: `python video_uniquifier.py --help`

Ключевые:
```
--copies N            копий из каждого видео (по умолчанию 5)
--segment window|sequential   способ работы с длинными видео (по умолч. window)
--audio mute|background|keep
--no-overlay          не накладывать оверлеи
--min-dur / --max-dur диапазон финальной длины (по умолч. 6 / 8)
--trim-min / --trim-max   обрезка с края, сек (по умолч. 0.01 / 0.10)
--speed-min / --speed-max отклонение скорости (по умолч. 0.01 / 0.10 = ±1…10%)
--no-noise / --no-sharpen / --no-zoom   выключить эффект
--noise-max / --sharpen-max / --zoom-max   макс. сила эффекта
--width / --height    формат кадра (по умолч. 1080 / 1920)
--fps N               целевой FPS (0 — как в источнике)
--workers N           параллельных процессов (0 — авто: cpu/2)
--crf N               качество x264 (меньше = лучше, по умолч. 20)
--seed N              воспроизводимый результат
--overwrite           перезаписывать существующие файлы
--ffmpeg / --ffprobe  явные пути к бинарникам
```

## Что делает с каждой копией

| Правило | Значение |
|---|---|
| Обрезка | 0.01–0.10 c с начала **или** конца (случайно) |
| Скорость | ±0.01–0.10 (1…10%), видео + звук, если звук остаётся |
| Длина | подгон под 6–8 c |
| Длинное видео | `window` — случайное окно 6–8 c; `sequential` — подряд идущие отрезки 6–8 c |
| Формат | вертикаль 9:16 = 1080×1920 (scale + crop краёв) |
| Цвет | brightness ±2–5%, contrast ±2–5%, saturation ±3–5%, gamma ±3–5% |
| Эффекты | шум + резкость + микро-зум (каждый вкл/выкл, сила настраивается) |
| Оверлей | случайный PNG (фейк-точки), случайные размер и позиция |
| Аудио | mute / background (трек с рандомной громкостью) / keep (оригинал) |
| Метаданные | очищаются (`-map_metadata -1`) |

**Имена файлов:** `имя_copy01.mp4`, а в режиме нарезки — `имя_seg01_copy01.mp4`.

## Частые вопросы

- **«ffmpeg не найден»** — не установлен FFmpeg или не в PATH. Установи (см. Быстрый старт)
  и перезапусти терминал/программу, либо впиши пути в поля ffmpeg/ffprobe.
- **Медленно** — `x264` уже многопоточный. Для черновиков: CRF 26, для финала: CRF 18.
  Число процессов по умолчанию = половина ядер, чтобы не перегружать CPU.
- **Ошибки не останавливают всё** — сбойные клипы пропускаются, причины пишутся в
  `uniquifier.log` и в окно лога.
- **Проверка уникальности** — после обработки приложение считает хеш каждой копии и
  пишет в лог `[OK] Все копии УНИКАЛЬНЫ` либо предупреждает о совпадениях (в т.ч. внутри
  одного источника). Отключается флагом `--no-verify` или галочкой в GUI.

## Полная уникальность каждой копии

Каждая копия разводится по 10+ независимым осям — по всем уровням, которые смотрят
алгоритмы дедупликации (проверено на реальных файлах: MD5, длительность, метаданные и
пиксели кадра у всех копий разные):

| Уровень | Что различается |
|---|---|
| Длина / скорость / обрезка | у каждой копии своя длительность |
| Геометрия | микро-зум + кроп → сдвиг кадра |
| Цвет | brightness / contrast / saturation / gamma (случайно) |
| Эффекты | шум + резкость |
| Оверлеи | случайное число фейк-точек в случайных местах |
| Битовый поток | перекодировка → разный размер/битрейт, разный MD5 |
| Метаданные | уникальные creation_time / comment / handler на каждую копию |
